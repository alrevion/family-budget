## Goal
Telegram Mini App с ботом-компаньоном для совместного учёта финансов двух человек (муж и жена) в узбекских сумах. Оба вбивают траты и доходы; система сама считает текущий баланс как «доходы − расходы», разделяя его на свободные деньги и деньги, отложенные в накопительные цели. Раз в месяц бот присылает отчёт из пяти блоков, по которому пара находит категорию для сокращения.

## Constraints
- Валюта: **узбекский сум (UZS)**, целые числа, без копеек. Суммы шестизначные — форматирование с разделителями обязательно.
- Пользователей ровно **два**, доступ по whitelist Telegram ID. Никакой регистрации, паролей, приглашений.
- Стек: **TypeScript, Cloudflare Workers + D1 + Mini App**, задеплоенные как один Worker. Cron Trigger для месячного отчёта.
- Графики рисуются **в браузере (Mini App)**, не на сервере — на Workers нет серверного рендеринга картинок.
- Бот работает через **webhook**, не polling.
- Максимальный срок скрытия траты — **полгода**.
- Один уровень категорий, без подкатегорий.
- Никаких отдельных счетов (карта/наличка/вклад) — один общий пул денег.
- Никакого AI, никаких советов, никакой интеграции с банками.

## Non-Goals (явно вне v1)
- AI-советник по накоплениям и оптимизации трат (v2, решение пользователя)
- Импорт выписок из банка, парсинг SMS/чеков
- Разделение по счетам (карта / наличка / вклад) и переводы между ними
- Подкатегории
- Регулярные/повторяющиеся платежи, лимиты и бюджеты на категорию
- Мультивалютность
- Более двух пользователей
- Свободный текстовый ввод с парсингом сумм (отклонён: «340» неоднозначно в сумах)

## Acceptance Criteria

### Ввод транзакций
- [ ] AC-1: Трата записывается за ≤3 тапа: сумма → категория → сохранить. Дата по умолчанию — сегодня.
- [ ] AC-2: Доход записывается тем же путём с переключателем расход/доход.
- [ ] AC-3: У каждой транзакции сохраняется автор (кто из двоих внёс).
- [ ] AC-4: Транзакцию можно отредактировать (сумма, категория, дата, комментарий) и удалить; баланс, цели и отчёты после этого пересчитываются немедленно.
- [ ] AC-5: При создании траты можно поставить флаг «скрытая» и выбрать срок раскрытия: 1 день / 1 неделя / 1 месяц / полгода.

### Скрытые траты
- [ ] AC-6: Сумма скрытой траты **входит** в общий баланс и в месячные итоги сразу — скрыты только категория, комментарий и авторство.
- [ ] AC-7: Второй пользователь видит скрытую трату как «Скрытая трата, раскроется <дата>» с видимой суммой.
- [ ] AC-8: После наступления даты раскрытия трата становится полностью видимой обоим без ручных действий.
- [ ] AC-9: Автор скрытой траты всегда видит её полностью.

### Баланс и цели
- [ ] AC-10: При первом запуске оба вводят стартовый остаток один раз; он записывается как доход категории «Стартовый остаток».
- [ ] AC-11: Главный экран Mini App показывает: **Свободно** (баланс минус отложенное в цели), **В целях**, траты за текущий месяц.
- [ ] AC-12: Можно создать несколько целей одновременно, у каждой название и целевая сумма.
- [ ] AC-13: Кнопка «Отложить в цель» переносит указанную сумму из свободных денег в конкретную цель. Это не расход — общий баланс не меняется.
- [ ] AC-14: Каждая цель показывает прогресс: отложено / цель, процент, сколько осталось.
- [ ] AC-15: Из цели можно вернуть деньги в свободные (отмена откладывания).

### Категории
- [ ] AC-16: Стартовый список: Продукты, Кафе и доставка, Транспорт, Жильё и коммуналка, Здоровье, Одежда, Развлечения, Дети, Подарки, Прочее.
- [ ] AC-17: Можно добавить свою категорию и переименовать существующую. Категорию с транзакциями удалить нельзя (только скрыть из списка выбора).

### Месячные отчёты
- [ ] AC-18: Первого числа Cron Trigger шлёт обоим сообщение «Отчёт за <месяц> готов» с кнопкой открытия Mini App.
- [ ] AC-19: Отчёт содержит круговую диаграмму долей категорий за месяц.
- [ ] AC-20: Отчёт содержит гистограмму сравнения с прошлым месяцем по категориям, с подписью изменения в процентах.
- [ ] AC-21: Отчёт содержит гистограмму итогов по месяцам за весь период наблюдений.
- [ ] AC-22: Отчёт содержит список топ-5 крупнейших отдельных трат месяца.
- [ ] AC-23: Отчёт содержит число «Отложено за месяц» = доходы − расходы за месяц.
- [ ] AC-24: Отчёт за любой прошлый месяц открывается из Mini App в любой момент.

### Доступ
- [ ] AC-25: Запросы от Telegram ID вне whitelist отклоняются и ботом, и Mini App.
- [ ] AC-26: Mini App проверяет подпись `initData` от Telegram на сервере при каждом запросе.

## Technical Context
- **Greenfield.** Рабочая папка пуста (только `.claude-flow/`). Существующего кода нет.
- Runtime: Cloudflare Workers (TypeScript). Роутинг — Hono или ручной, на усмотрение исполнителя.
- БД: Cloudflare D1 (SQLite). Таблицы: `users`, `categories`, `transactions`, `goals`, `goal_allocations`.
- Один Worker обслуживает три вещи: webhook Telegram, JSON API для Mini App, статику Mini App.
- Cron Trigger: 1-е число каждого месяца.
- Графики: любая браузерная библиотека в Mini App. Серверный рендеринг картинок недоступен.
- Форматирование сумм: `Intl.NumberFormat('ru-RU')`, суффикс «сум», без дробной части.
